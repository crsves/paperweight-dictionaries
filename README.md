# Paperweight Dictionaries

Dictionaries for [Dictionary by Paperweight](https://github.com/crsves/paperweight-dictionaries/releases).

Data only. Each release carries compiled dictionary files and a `manifest.json`
listing id, language, version, size, sha256, license and attribution. The app
downloads from here and verifies every file before installing it.

## Sources

- Wiktionary, via [kaikki.org](https://kaikki.org/) — CC BY-SA 4.0
- Open English WordNet — CC BY 4.0

Each file keeps its source's license; attribution is shown in the app.
